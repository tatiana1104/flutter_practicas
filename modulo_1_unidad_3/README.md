# 🧭 Módulo 1 - Unidad 3

## Navegación Compleja y Gestión de Estado Profesional

Unidad dedicada a la creación de flujos avanzados y a la gestión de estado eficiente en aplicaciones Flutter.

### 🔎 Descripción general

- Navegación estructurada: rutas nombradas, argumentos, navegación condicional y deep links.
- Gestión de estado profesional: `setState`, `InheritedWidget`, `Provider`, patrones y arquitecturas MVVM.
- Organización de capas de UI, lógica y datos para aplicaciones mantenibles.
- Desarrollo de aplicaciones con múltiples pantallas, transiciones y experiencia de usuario coherente.
- Ejemplos prácticos: ecommerce, menús, selección de temas y comparaciones de estado.

### 🎯 Resultados esperados

- Construir arquitecturas de navegación escalables.
- Gestionar estado local y global con patrones adecuados.
- Separar claramente la presentación de la lógica de negocio.
- Mantener código limpio y preparado para crecimiento.

### 🧩 Contenido clave

- Rutas y navegación en Flutter.
- Estado local vs estado compartido.
- Provider y patrones de arquitectura.
- Organización de carpetas y responsabilidades.
- Aplicaciones multipantalla y gestión de sesiones.

### 📦 Dependencias externas

Además de los paquetes incluidos en el proyecto base, se pueden añadir dependencias para resolver necesidades específicas:

- `provider`, `flutter_bloc`, `riverpod`: para una gestión de estado profesional.
- `get_it`: para inyección de dependencias y desacoplar lógica.
- `go_router`, `auto_route`: para navegación compleja y rutas dinámicas.

Estas dependencias se seleccionan cuando la aplicación requiere mayor escalabilidad, organización y patrones de arquitectura claros.
