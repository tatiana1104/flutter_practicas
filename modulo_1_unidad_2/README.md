# 🎨 Módulo 1 - Unidad 2

## UI/UX Avanzado, Widgets Profesionales y Diseño Multiplataforma

Unidad orientada a la construcción de interfaces profesionales, usables y adaptadas a múltiples plataformas.

### 🔎 Descripción general

- Diseño centrado en el usuario con principios de UX y jerarquía visual.
- Creación de widgets avanzados: formularios, tarjetas, listas dinámicas y componentes reutilizables.
- Estrategias de diseño responsivo para móvil, web y escritorio.
- Implementación de temas globales y gestión de estilos.
- Proyectos prácticos con experiencias de usuario consistentes y refinadas.

### 🎯 Resultados esperados

- Aplicar diseño UI/UX sólido en aplicaciones Flutter.
- Desarrollar interfaces adaptativas y accesibles.
- Gestionar temas y estilos de forma escalable.
- Construir aplicaciones con formularios avanzados y validaciones profesionales.

### 🧩 Contenido clave

- Principios de diseño visual y usabilidad.
- Widgets personalizados y componentes escalables.
- Layouts responsivos y adaptativos.
- Manejo de temas, tipografías y paletas de color.
- Validaciones y experiencias interactivas.

### 📦 Dependencias externas

El proyecto base usa las dependencias estándar de Flutter. Si se incluyen paquetes adicionales, debe explicarse su propósito:

- `flutter_svg`, `cached_network_image`: para imágenes y recursos optimizados.
- `animations`, `flutter_staggered_grid_view`: para mejorar interacciones y layouts complejos.
- `intl`: para localización y formato de fechas/números.

Estas librerías se utilizan para crear interfaces más profesionales y acelerar el desarrollo sin sacrificar calidad.
