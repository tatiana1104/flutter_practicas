# Índice del curso Flutter

Este README funciona como un índice general de todo lo visto hasta el momento en el workspace `flutter_practicas`.

## 📚 Estructura general

- `modulo_1`
  - `unidad_1`
  - `unidad_2`
  - `unidad_3`
- `modulo_2`
  - `unidad_1`
  - `unidad_2`

Cada unidad cuenta con su propio `README.md` que describe el tema, objetivos y dependencias externas.

## 🧭 Resumen de unidades

### Módulo 1 - Unidad 1
`Fundamentos de Flutter, Dart y Entorno Profesional`

- Conceptos básicos de Dart: variables, tipos, funciones y clases.
- Introducción a Flutter: widgets, árbol de widgets y ciclo de vida.
- Configuración del entorno de desarrollo profesional.
- Buenas prácticas: organización de proyecto, `pubspec.yaml`, control de versiones.
- Proyectos iniciales: `calculadora`, `primera_app`, `segunda_app`, ejercicios de clase.

### Módulo 1 - Unidad 2
`UI/UX Avanzado, Widgets Profesionales y Diseño Multiplataforma`

- Principios de UI/UX y diseño centrado en el usuario.
- Widgets profesionales: tarjetas, formularios, listas y componentes personalizados.
- Diseño responsivo para móvil, web y escritorio.
- Temas globales y estilos.
- Proyectos: `catalogo_app`, `ejercicio_1`, `Formulario_Dinamico_App`, `login_validation`.

### Módulo 1 - Unidad 3
`Navegación Compleja y Gestión de Estado Profesional`

- Navegación avanzada: rutas nombradas, argumentos y flujos multipantalla.
- Gestión de estado con patrones profesionales.
- Separación de capas UI, lógica y datos.
- Proyectos: `app_ecommerce`, `comparativa_estado`, `navegacion_multipantalla`, `selector_temas`, `shop_mvvm`.

### Módulo 2 - Unidad 1
`Integración de APIs, Autenticación y Seguridad en Cliente`

- Consumo de APIs REST con distintos clientes.
- Manejo de peticiones y errores.
- Autenticación, tokens y persistencia segura en cliente.
- Proyectos: `api`, `apirest`, `app_productos`, `blog_app`, `dio_exercise`.

### Módulo 2 - Unidad 2
`Firebase Backend y Servicios Cloud`

- Conexión con Firebase y servicios cloud.
- Autenticación, Firestore, Realtime Database y Storage.
- Funciones en la nube y sincronización en tiempo real.
- Proyecto: `pack_and_go`.

## 🛠️ Dependencias y justificación

Cada unidad incluye un apartado para dependencias externas y explica:

- por qué se agrega un paquete adicional,
- para qué se utiliza,
- qué problema resuelve frente al SDK base de Flutter.

## 🚀 Cómo usar este índice

1. Abrir la unidad deseada.
2. Leer el `README.md` de la unidad para conocer objetivos y temas.
3. Ejecutar el proyecto de ejemplo con `flutter run` dentro de la carpeta correspondiente.
4. Revisar las dependencias externas cuando se usen paquetes adicionales.
