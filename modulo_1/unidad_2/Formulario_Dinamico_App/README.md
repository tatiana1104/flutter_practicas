Una aplicación Flutter moderna con formulario de registro dinámico que incluye validación en tiempo real de email y contraseña.

---

## ✨ Características

- 📧 **Validación de Email**: Validación en tiempo real con formato de email correcto
- 🔒 **Validación de Contraseña**: Requiere mínimo 8 caracteres
- ⚡ **Validación en Tiempo Real**: El botón de registro se habilita automáticamente cuando el formulario es válido
- 🎨 **Material Design 3**: Interfaz de usuario moderna y responsiva
- 🔄 **Feedback Visual**: Indicadores visuales del estado de validación

---

## 📋 Requisitos Previos

Antes de ejecutar este proyecto, asegúrate de tener instalado:

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (versión 3.9.2 o superior)
- [Dart SDK](https://dart.dev/get-dart) (versión 3.9.2 o superior)
- Un editor de código como [VS Code](https://code.visualstudio.com/) o [Android Studio](https://developer.android.com/studio)

---

## 🚀 Instalación

1. **Clona el repositorio:**
   
```bash
   git clone <url-del-repositorio>
   cd Formulario_Dinamico_App
   
```

2. **Instala las dependencias:**
   
```bash
   flutter pub get
   
```

3. **Ejecuta la aplicación:**
   
```bash
   flutter run
   
```

---

## 📱 Uso de la Aplicación

1. **Campo de Email**: Ingresa tu dirección de correo electrónico
   - El sistema validará el formato automáticamente
   - Mostrará un mensaje de error si el formato es incorrecto

2. **Campo de Contraseña**: Ingresa una contraseña segura
   - Mínimo 8 caracteres requeridos
   - La contraseña se oculta por seguridad

3. **Botón de Registro**: 
   - Se habilita automáticamente cuando ambos campos son válidos
   - Al hacer clic, muestra un mensaje de éxito
