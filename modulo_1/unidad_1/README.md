# 🚀 Módulo 1 - Unidad 1

## Fundamentos de Flutter, Dart y Entorno Profesional

Esta unidad establece la base técnica y profesional para el desarrollo de aplicaciones móviles con Flutter y Dart.

### 🔎 Descripción general

- Introducción a Dart como lenguaje principal del ecosistema Flutter.
- Exploración del ciclo de vida de widgets y del árbol de widgets.
- Configuración de entorno profesional: Flutter SDK, VS Code/Android Studio, emuladores y dispositivos físicos.
- Estándares de proyecto: estructura de carpetas, `pubspec.yaml`, control de versiones y documentación.
- Prácticas iniciales: calculadora, app simple y ejercicios de programación.

### 🎯 Resultados esperados

- Dominio de los fundamentos de Dart: variables, tipos, estructuras de control, funciones y clases.
- Comprensión clara de la arquitectura de un proyecto Flutter.
- Entorno de desarrollo configurado de forma completa y estable.
- Capacidad para crear aplicaciones pequeñas con buenas prácticas profesionales.

### 🧩 Contenido clave

- Variables, operadores y estructuras de control en Dart.
- Funciones, clases y objetos.
- Widgets básicos y composición de UI.
- Configuración y mantenimiento de un proyecto Flutter.
- Buenas prácticas de organización y documentación.

### 📦 Dependencias externas

El proyecto base de Flutter incluye los paquetes esenciales. Si se agregan dependencias adicionales, debe justificarse con un motivo concreto:

- `provider`, `riverpod` o `bloc`: para gestión de estado más clara y escalable.
- `http`, `dio`: para consumir APIs externas de forma robusta.
- `firebase_core`, `cloud_firestore`, `firebase_auth`: para integración con Firebase.

Estas dependencias se utilizan cuando la funcionalidad requerida no está cubierta por el SDK básico de Flutter y se buscan soluciones profesionales, mantenibles y seguras.
