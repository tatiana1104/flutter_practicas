## 📱 Descripción

Este proyecto es una aplicación Flutter diseñada para practicar y dominar los conceptos de navegación entre múltiples pantallas. Es ideal para desarrolladores que están comenzando con Flutter y desean entender cómo manejar rutas, navegación entre páginas y gestión de estado básico.

### ✨ Características

- 🏠 **Pantalla de Inicio** - Punto de entrada principal de la aplicación
- 🔐 **Pantalla de Login** - Interfaz de autenticación de usuario
- 👤 **Pantalla de Perfil** - Visualización de información del usuario
- 🛤️ **Gestión de Rutas** - Implementación de navegación profesional
- 🎯 **Arquitectura Limpia** - Separación de responsabilidades

---

## 📂 Estructura del Proyecto

```
lib/
├── main.dart              # Punto de entrada de la aplicación
├── app.dart               # Configuración principal de la app
├── routes/
│   └── app_routes.dart    # Definición de rutas de navegación
├── screens/
│   ├── home_screen.dart   # Pantalla principal
│   ├── login_screen.dart  # Pantalla de inicio de sesión
│   └── profile_screen.dart# Pantalla de perfil de usuario
└── services/
    └── auth_service.dart  # Servicio de autenticación
```

## 🛠️ Instalación

### Prerrequisitos

- Flutter SDK 3.x o superior
- Dart SDK 3.x o superior
- Editor de código recomendado: VS Code o Android Studio

### Pasos de Instalación

1. **Clonar el repositorio**
   
```bash
   git clone https://github.com/tatiana1104/flutter_practicas.git
   cd modulo_1/unidad_3/navegacion_profesional   
```

2. **Instalar dependencias**
   
```bash
   flutter pub get   
```

3. **Ejecutar la aplicación**
   
```bash
   flutter run
```
