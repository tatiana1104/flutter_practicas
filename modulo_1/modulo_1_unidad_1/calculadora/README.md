## 📱 Descripción

**Calculadora Flutter** es una aplicación de calculadora sencilla y elegante desarrollada con el framework Flutter. Cuenta con un diseño moderno basado en Material Design 3, tema oscuro elegante y botones con acabados profesionales en color dorado.

✨ *Una calculadora bonita, funcional y fácil de usar.*

---

## 🎨 Características Principales

| Característica | Descripción |
|----------------|-------------|
| 🎭 **Tema Oscuro** | Interfaz oscura moderna y elegante |
| 📐 **Material Design 3** | Diseño siguiendo las guías de Material You |
| ✨ **Botones Dorados** | Acabado profesional en color dorado |
| 📱 **Diseño Responsivo** | Se adapta a diferentes tamaños de pantalla |
| 🌈 **Sombras y Efectos** | Animaciones y sombras para mayor profundidad |
| 🔢 **Operaciones Básicas** | Suma, resta, multiplicación y división |

---

## 📋 Requisitos Previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- **Flutter SDK** (versión 3.9.2 o superior)
- **Dart SDK** (versión 3.9.2 o superior)
- Un editor de código como **VSCode** o **Android Studio**

---

## 🚀 Instalación y Ejecución

### 1. Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
cd calculadora
```

### 2. Obtener las dependencias

```bash
flutter pub get
```

### 3. Ejecutar la aplicación

```bash
flutter run
```
