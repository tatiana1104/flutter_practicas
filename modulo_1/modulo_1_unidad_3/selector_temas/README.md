# 🎨 Selector de Temas

[![Flutter](https://img.shields.io/badge/Flutter-3.9.2-blue)](https://flutter.dev)
[![Dart](https://img.shields.io/badge/Dart-3.9.2-blue)](https://dart.dev)

Una aplicación Flutter que implementa diferentes enfoques de gestión de estado para el cambio de temas (claro/oscuro).

## 📱 Acerca del Proyecto

Este proyecto es una demostración práctica de tres bibliotecas populares de gestión de estado en Flutter:

| Biblioteca | Descripción |
|------------|-------------|
| 🔵 **Provider** | Gestión de estado simple y reactiva |
| 🟣 **Flutter Bloc** | Implementación del patrón BLoC (Business Logic Component) |
| 🟢 **Riverpod** | Gestión de estado moderna y escalable |

## ✨ Características

- 🔄 Cambio dinámico entre tema claro y oscuro
- 📚 Implementación de tres enfoques diferentes de gestión de estado
- 🎯 Interfaz de usuario intuitiva y funcional

## 🚀 Empezando

Este proyecto es un punto de partida para una aplicación Flutter.

### Requisitos Previos

- 🛠️ Flutter SDK instalado (versión 3.9.2 o superior)
- 💻 Un editor de código como VS Code o Android Studio

### Instalación

1. 📥 Clona el repositorio
2. 📦 Ejecuta `flutter pub get` para instalar las dependencias
3. ▶️ Ejecuta `flutter run` para iniciar la aplicación

### 📚 Dependencias

Las siguientes dependencias se utilizan en este proyecto:

```yaml
dependencies:
  provider: ^6.1.5+1          # Gestión de estado con Provider
  flutter_bloc: ^9.1.1        # Implementación del patrón BLoC
  flutter_riverpod: ^3.2.1   # Gestión de estado con Riverpod
```
