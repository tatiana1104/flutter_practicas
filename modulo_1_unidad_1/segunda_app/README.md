## 📋 Descripción

`segunda_app` es una aplicación inicial creada para practicar la organización de un proyecto Flutter. Incluye la configuración básica de un proyecto, dependencias estándar y una plantilla lista para extender con nuevas pantallas.

## ✨ Características

- 📦 Estructura de proyecto Flutter lista para desarrollo
- 🧩 Dependencias básicas instaladas: `cupertino_icons`
- 🚀 Ideal para aprender el flujo de trabajo `flutter pub get` y `flutter run`
- 📝 Base para agregar nuevas funcionalidades sin partir de cero

## 🛠️ Dependencias y por qué se usan

- `flutter`: SDK principal para construir la aplicación
- `cupertino_icons`: conjunto de íconos para compatibilidad de estilo iOS

## ⚙️ Instalación

1. Abre una terminal en `modulo_1_unidad_1/segunda_app`
2. Ejecuta:

```bash
flutter pub get
```

3. Ejecuta la aplicación:

```bash
flutter run
```

## 📂 Estructura del proyecto

```
segunda_app/
├── lib/
│   └── main.dart
├── pubspec.yaml
└── README.md
```

## 🎯 Objetivo

El objetivo principal de `segunda_app` es servir como un punto de partida sencillo para experimentar con Flutter, agregar nuevas pantallas, formularios o integraciones de API en próximas prácticas.
