# ☁️ Módulo 2 - Unidad 2

## Firebase Backend y Servicios Cloud

Unidad dedicada al uso de Firebase como backend y a la construcción de servicios en la nube para aplicaciones Flutter.

### 🔎 Descripción general

- Configuración de Firebase y conexión con Flutter.
- Uso de autenticación, Firestore, `Realtime Database` y Storage.
- Servicios cloud: funciones, notificaciones push y sincronización en tiempo real.
- Arquitectura de backend como servicio para aplicaciones móviles.
- Proyectos prácticos con datos persistentes y backend integrado.

### 🎯 Resultados esperados

- Conectar aplicaciones Flutter con Firebase de manera profesional.
- Gestionar datos en la nube y almacenamiento seguro.
- Implementar backend serverless y servicios cloud.
- Crear aplicaciones con sincronización de datos en tiempo real.

### 🧩 Contenido clave

- Firebase Authentication.
- Firestore y Realtime Database.
- Firebase Storage.
- Funciones en la nube y notificaciones.
- Integración backend/frontend en Flutter.

### 📦 Dependencias externas

Firebase no forma parte del SDK base de Flutter, por lo que se usan dependencias específicas cuando el proyecto requiere backend cloud:

- `firebase_core`: conexión base con Firebase.
- `firebase_auth`: autenticación de usuarios.
- `cloud_firestore`, `firebase_database`, `firebase_storage`: persistencia y almacenamiento.

Estas librerías se utilizan para integrar servicios cloud de Firebase de forma profesional y segura.
