# 🔐 Módulo 2 - Unidad 1

## Integración de APIs, Autenticación y Seguridad en Cliente

Unidad enfocada en la integración con servicios externos, la autenticación de usuarios y la protección de datos en aplicaciones Flutter.

### 🔎 Descripción general

- Consumo de APIs REST con clientes como `http` y `Dio`.
- Manejo de peticiones y respuestas: GET, POST, PUT, DELETE y manejo adecuado de errores.
- Implementación de autenticación: login, refresh tokens y persistencia de sesión.
- Seguridad en cliente: almacenamiento seguro de credenciales, validación de datos y protección contra fugas.
- Proyectos prácticos con API de productos, blog y servicios personalizados.

### 🎯 Resultados esperados

- Integrar APIs externas de forma segura y escalable.
- Gestionar flujos de autenticación robustos.
- Manejar errores de red y estados de carga de forma profesional.
- Proteger información sensible en el cliente usando buenas prácticas.

### 🧩 Contenido clave

- Arquitectura de consumo de APIs.
- Autenticación basada en tokens.
- Persistencia y cifrado en el cliente.
- Manejo de estados de carga y errores.
- Validación y protección de datos.

### 📦 Dependencias externas

El proyecto base incluye las dependencias de Flutter, pero al integrar APIs y seguridad se justifican librerías externas:

- `http`, `dio`: para peticiones HTTP avanzadas y manejo de interceptores.
- `flutter_secure_storage`: para almacenar tokens y credenciales de forma segura.
- `json_serializable`, `freezed`: para modelado y serialización de datos.

Estas dependencias se emplean para mejorar la seguridad, fiabilidad y mantenibilidad del cliente.
